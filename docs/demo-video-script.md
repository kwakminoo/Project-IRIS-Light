# IRIS 설치·동작 데모 영상 대본

README 상단에 연결할 **YouTube 데모 영상** 제작용 대본입니다.
목표 길이 **3분 내외**, 대상은 **"파이썬을 처음 깔아보는 사람"** 입니다.

> 영상을 올린 뒤 README의 `<!-- DEMO_VIDEO -->` 블록에 링크를 넣으면 끝납니다.
> 넣는 방법은 이 문서 §5 참고.

---

## 1. 촬영 전 준비

| 항목 | 내용 |
|------|------|
| **환경** | 되도록 **깨끗한 PC 또는 새 Windows VM**. "진짜 처음부터 설치된다"는 게 이 영상의 핵심 메시지입니다 |
| **해상도** | 1920×1080 / 60fps. 녹화는 OBS Studio(무료) 권장 |
| **글꼴 크기** | 터미널 글꼴을 **16pt 이상**으로. 모바일에서 보는 사람이 많습니다 |
| **정리** | 바탕화면 아이콘·알림·개인정보(계정명, 메일 등) 정리. 브라우저 탭 정리 |
| **비우기** | `.venv`, `.venv-voice`, `.env` 삭제 후 시작 (`git clean -xdn` 으로 먼저 확인) |
| **미리 준비** | 다운로드가 느린 구간은 **미리 한 번 돌려서 캐시**해 두면 대기 시간이 줄어듭니다 |
| **가리기** | `.env`·API 키·Hermes 키가 화면에 노출되지 않도록 주의. 노출되면 편집에서 블러 |

## 2. 구성 (총 3:00 목표)

### 씬 0 — 훅 (0:00 – 0:12)

**화면**: IRIS HUD가 이미 떠 있고, 채팅에 요청을 넣자 도구 로그가 주르륵 흐르는 장면 (완성형 먼저 보여주기)

**내레이션**
> "월 몇만 원짜리 AI 구독 없이, 내 PC에서 도는 AI 에이전트입니다.
> 설치는 파일 하나 더블클릭이면 끝납니다."

**자막**: `IRIS — 오픈소스 데스크톱 AI 에이전트`

---

### 씬 1 — 내려받기 (0:12 – 0:35)

**화면**
1. GitHub 저장소 페이지 → `Code` → `Download ZIP`
2. 압축 해제, 폴더 열기
3. (개발자용 대안 자막) `git clone https://github.com/kwakminoo/Project-IRIS-Light.git`

**내레이션**
> "저장소를 ZIP으로 받아서 압축을 풉니다. git을 쓰시는 분은 clone 하셔도 됩니다."

**자막**: `1단계 · 내려받기`

---

### 씬 2 — 자동 설치 (0:35 – 1:20) ⭐ 이 영상의 핵심

**화면**
1. 폴더 안에서 **`setup.bat` 을 더블클릭** (마우스 커서가 명확히 보이게)
2. 콘솔 창이 뜨고 `[1/6] … [6/6]` 단계가 순서대로 초록색 `OK` 로 채워지는 것
3. `설치 완료` 배너

**내레이션**
> "`setup.bat`을 더블클릭합니다. 파이썬을 찾고, 가상환경을 만들고,
> 필요한 패키지를 전부 설치한 다음, 제대로 깔렸는지 검증까지 자동으로 합니다.
> 명령어를 외울 필요도, 파이썬 경로를 만질 필요도 없습니다."

**편집**: 패키지 설치 다운로드 구간은 **4배속 + 진행 표시**로 압축. "수 분" 이라는 자막을 넣어 솔직하게.

**자막**: `2단계 · setup.bat 더블클릭 — 이게 전부입니다`

> 💡 파이썬이 없는 PC로 찍으면 스크립트가 **설치 링크와 winget 명령을 안내하는 화면**이
> 나옵니다. 이 장면을 5초쯤 넣으면 "실패해도 뭘 해야 할지 알려준다"는 인상이 강해집니다.

---

### 씬 3 — 첫 실행과 시작 위저드 (1:20 – 2:05)

**화면**
1. `run.bat` 더블클릭 → IRIS HUD 기동
2. **시작 위저드** 등장
3. Core 단계가 진행되는 모습: Ollama 설치 → 모델 pull → Hermes 설치 → provider 연결 → gateway 기동
4. Optional 단계에서 「나중에」를 눌러 넘어가는 모습

**내레이션**
> "실행하면 시작 위저드가 뜹니다. Ollama와 Hermes 같은 백엔드를
> 하나씩 안내하면서 자동으로 깔아 줍니다.
> 음성이나 에뮬레이터 같은 선택 기능은 나중에 켜도 됩니다."

**편집**: 실제 설치 대기는 길므로 **컷 편집 + 배속**. 단계 이름 자막을 얹어 흐름이 보이게.

**자막**: `3단계 · 첫 실행 — 백엔드까지 자동 설치`

---

### 씬 4 — 실제 동작 (2:05 – 2:45)

**화면**: 채팅에 한 가지 요청을 넣고 끝까지 완주. 아래 중 **하나만 고르세요** (여러 개 보여주면 산만해집니다).

| 후보 | 장점 |
|------|------|
| "이 폴더 파이썬 파일 개수 세서 정리해 줘" | 파일·터미널 도구 호출이 눈에 보임. 가장 안전 |
| "오늘 «주제» 검색해서 세 줄로 정리해 줘" | 웹 도구 + 인용 칩(citation chips)이 보임 |
| 음성으로 말 걸기 → 아이리스가 목소리로 답변 | 임팩트 최고. 단, 음성 런타임 세팅 필요 |

**보여줘야 할 것**: 사고/도구 로그가 **스트리밍으로 흐르는 장면**. 이게 "그냥 챗봇이 아니라 에이전트"라는 증거입니다.

**내레이션**
> "요청을 보내면 모델이 답만 하는 게 아니라, 실제로 도구를 호출해서
> 파일을 읽고 명령을 실행합니다. 무슨 도구를 왜 썼는지도 그대로 보여 줍니다."

**자막**: `4단계 · 자연어로 요청 → 실제 작업 수행`

## 5. README에 링크 넣는 법

`README.md` 상단의 아래 블록을 찾아서, 자리표시자 세 군데를 실제 값으로 바꾸면 됩니다.

```markdown
<!-- DEMO_VIDEO:START -->
[![IRIS 설치·동작 데모](https://img.youtube.com/vi/VIDEO_ID/maxresdefault.jpg)](https://youtu.be/VIDEO_ID)
<!-- DEMO_VIDEO:END -->
```

- `VIDEO_ID` — 유튜브 주소의 `https://youtu.be/` 뒤 11자리
  (예: `https://youtu.be/dQw4w9WgXcQ` → `dQw4w9WgXcQ`)
- 썸네일 이미지는 유튜브가 자동으로 제공하므로 따로 올릴 필요 없습니다.
- GitHub README는 동영상 임베드를 지원하지 않아, **썸네일 이미지를 클릭하면
  유튜브로 이동하는** 위 방식이 표준입니다.
