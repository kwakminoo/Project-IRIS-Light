# Prompt: 부수 호출이 게이트웨이 설정 칸을 덮지 않는다

기준: `docs/code-review/다중채팅-동시작업-2단계-분석보고서.md` 4절·7절. 문서 번호 IRIS-SEC-2026-1012-01.

```text
Context:
- 채팅 완료 요청은 model과 provider만 싣는다. 업스트림 주소와 키는 게이트웨이 설정 한 칸이다.
  그 칸의 주인은 마지막 set_inference_model이다.
- HermesChatWorker.run은 set_inference_model을 부르지 않는다. 그 경로는 다시 만들지 않는다.
- 제목·루틴·인수인계는 backend_call._hermes로 간다. 지금은 set_inference_model로 그 칸의
  주소와 키를 덮은 뒤, provider 없이 stream_chat을 보낸다. 광고 모델이 하나면 이름이 hermes-agent로 바뀐다.
- 피커 변경과 게이트웨이 재접속의 HermesModelSyncWorker도 같은 칸을 쓴다. 그 쓰기는 기본 모델 동기화다.
- X-Hermes-Session-Id를 넣으면 본문의 이전 턴이 state.db 기록으로 바뀐다. 세션 헤더 없음은 미완료가 아니다.
- 키 값은 완료 본문·trace_payload·활동 줄에 없다. CLI argv에도 넣지 않는다.

Goal:
1) 제목·루틴·인수인계가 진행 중 채팅의 설정 칸을 덮지 않는다.
   backend_call._hermes는 set_inference_model을 호출하지 않는다.
2) 그 호출은 타깃에 provider가 있을 때만 stream_chat에 provider를 넘긴다.
   광고 이름이 하나여도 업스트림 모델명을 유지한다. provider가 없으면 resolve_request_model을 유지한다.
3) 페이로드, 로그, 활동 줄, CLI argv에 api_key 값을 넣지 않는다.
4) 채팅 완료 요청과 부수 호출 모두 X-Hermes-Session-Id와 X-Hermes-Session-Key를 넣지 않는다.

Constraints:
- HermesModelSyncWorker의 set_inference_model은 유지한다. 설정 한 칸이 남는다.
  서로 다른 API 주소 둘을 동시에 격리됐다고 적거나 테스트로 단정하지 않는다.
- 슬롯에 base_url과 api_key를 두지 않는다. inference_provider를 주소 원본으로 읽기 시작하지 않는다.
- 요청 본문에 base_url·api_key를 넣지 않는다. 키를 로그에 싣는 안은 쓰지 않는다.
- 헤르메스 소스, direct_model_requests, Sessions API, Git worktree는 넣지 않는다.
- acquire_project / acquire_wiki 타임아웃, ide.open_file, ide.marketplace_install, ide.set_project_root는 넣지 않는다.
- hermes_ollama_guard의 접속 확인용 set_inference_model은 이 단계에서 빼지 않는다.
- 채팅 워커에 이미 있는 provider 인자 방식을 그대로 쓴다. 새 호출 형식을 만들지 않는다.

Interface:
- _hermes(route, messages, stop): route.target이 있으면 model은 target.model,
  provider는 target.provider다. target이 없으면 model은 route.model이고 provider는 넘기지 않는다.
- HermesClient 생성에 쓰는 route.api_key는 게이트웨이 인증이다. stream_chat 인자로 넘기지 않는다.
- set_inference_model 호출 횟수는 0이다.

검증:
- tests/test_request_model.py
  타깃이 있는 부수 호출은 set_inference_model이 0이고, stream_chat의 model·provider가 타깃과 같다.
  stream_chat 키워드에 api_key가 없다.
- tests/test_handoff_summary_worker.py
  인수인계 허메스 경로는 설정 칸을 쓰지 않고, 푼 업스트림 모델명으로 스트림한다.
- 기존 검사

.venv\Scripts\python.exe -m unittest tests.test_request_model tests.test_handoff_summary_worker tests.test_hermes_model_failover
.venv\Scripts\python.exe -m iris.ui._check_conversation_switch_cancel
.venv\Scripts\python.exe -m iris.ui._check_turn_followup
```
