# Prompt: 같은 모델로 채팅 둘의 루프를 동시에 둔다

기준: `docs/code-review/다중채팅-동시작업-구현보고서.md` 1단계, `docs/code-review/다중채팅-동시작업-1단계-구현보고서.md`.

```text
Context:
- ChatSession은 대화 id와 DB 기록만 나눈다. ChatTurnGate.busy, UserTurnDispatcher._active, MainWindow._chat_worker는 창에 하나다.
- 키보드 전송 _on_user_text는 session_id 없이 UserTurnDispatcher.submit으로 간다.
- _load_conversation은 busy이면 _cancel_current_turn(reason="conversation_switch")를 호출한다. 진행 중 답이 죽는다.
- 이어하기 상한은 iris/runtime/turn_followthrough.py의 CAP = 8이다. 창에 횟수가 하나라 전환하면 0이 된다.
- 평소 경로는 원격 API의 한 모델이다. 그 모델은 요청을 여러 건 받는다. 막힌 곳은 아이리스의 실행 슬롯 하나다.

Goal:
1) 대화 id → 슬롯 맵을 MainWindow.__init__에서 만든다. 첫 전송 때 창 속성을 새로 만들지 않는다.
   슬롯에 둔다: 워커, 점유(게이트), 턴 id, 무시 플래그, 이어하기 횟수·목표·세대, 도구 성공 횟수, 아직 화면에 안 붙은 부분 응답.
2) 키보드·음성 전송은 지금 화면의 대화 id를 실어 그 슬롯으로 보낸다. 활성 턴은 대화 id별. 동시 실행은 2.
   같은 채팅의 다음 입력은 그 채팅 큐에서 기다린다. 셋째 채팅은 그 채팅에서 기다리고, 진행 중 둘을 취소하지 않는다.
3) 전환은 화면 기록과 구체만 바꾼다. request_cancel(conversation_switch)을 호출하지 않는다. 백그라운드 이어하기를 0으로 만들지 않는다.
   토큰은 그 대화 DB에만 붙인다. 화면 첨부는 그 id가 포그라운드일 때만.
4) 정지 버튼은 포그라운드 슬롯만 취소한다.
5) 쓰기 잠금. IDE, project.write_file, 터미널, 열린 프로젝트에서 도는 명령은 창에 잠금 하나. 쥔 대화만 실행하고 다른 슬롯은 그 잠금에서 기다린다.
   위키 노트는 상대 경로마다 잠금 하나. 다른 경로는 동시에 쓸 수 있다. 읽기·검색·조사는 잠금 밖.
6) 구체는 창에 하나. 포그라운드가 생성이면 돌고, 쉬면 쉰다. 뒤 루프는 그 표시와 상관없이 계속된다.
7) 마이크도 TTS도 하나. 인식 결과는 지금 화면의 대화 id로만 들어간다. TTS는 그 채팅만 읽는다.
   다른 채팅으로 옮기면 읽던 TTS는 멈춘다. 옮겨 간 채팅에, 자리를 비운 동안 끝난 새 답이 있으면 그 답을 한 번 읽는다.
   보고 있지 않은 채팅이 끝났다고 TTS가 끼어들지 않는다.
8) 이어하기는 슬롯마다 센다. CAP 8은 유지한다. A의 횟수가 B의 상한에 더해지거나, 화면 전환만으로 0이 되지 않는다.

Constraints:
- 헤르메스 소스, 게이트웨이 프로세스, iris/core, set_inference_model, Git worktree, 요청 단위 model/provider는 넣지 않는다.
- 위키 보관 경로 projects/<슬러그>/chats/<대화 id>.md는 유지한다. 슬롯의 키가 아니다.
- 메일·캘린더 패널은 이 맵으로 바꾸지 않는다.
- 진행 중 슬롯이 있을 때 모델 피커로 다른 모델을 고르는 분리는 2단계다. 피커를 막거나 set_inference_model을 지우지 않는다.
- 슬롯 예외가 창을 죽이지 않게, 맵과 이어하기 필드는 생성자에서 있다.

Interface:
- iris/runtime/chat_run_slot.py: ChatRunMap.slot(대화 id), owning(턴 id). MAX_CONCURRENT = 2.
- UserTurnDispatcher: 세션별 활성 턴. 동시 2. 같은 세션은 큐. finish_active_turn(턴 id)는 그 세션만 끝내고 다음을 꺼낸다.
- MainWindow._on_user_text / 음성 전송: session_id = 지금 대화 id.
- MainWindow._load_conversation: 취소·이어하기 삭제 없음. 떠날 때 부분 응답은 그 슬롯에 둔다. 돌아올 때 생성이면 구체가 돌고 부분 응답을 화면에 잇는다.
- 백그라운드 토큰·완료·실패는 보이는 채팅 로그를 바꾸지 않는다. 완료 본문은 그 대화 DB에 쓴다.
- iris/runtime/session_write_lock.py: 프로젝트 잠금은 하나, 위키는 상대 경로마다 하나. call_registered가 쓰기 액션에서 잡고 끝나면 푼다.
- 창을 닫을 때는 슬롯의 워커를 모두 취소한다.

검증:
.venv\Scripts\python.exe -m unittest tests.test_user_turn_dispatcher
.venv\Scripts\python.exe -m iris.ui._check_conversation_switch_cancel
.venv\Scripts\python.exe -m iris.runtime.session_write_lock
.venv\Scripts\python.exe -m iris.ui._check_turn_followup
```
