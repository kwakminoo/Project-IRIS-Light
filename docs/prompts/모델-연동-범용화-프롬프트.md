## 0. 목표 (수용 기준)

**어느 제공자의 어느 모델이든, 설정에서 Base URL + API Key를 넣고 「테스트」를 누르면 그대로 사용 가능할 것.**

수용 기준은 다음 6건 전부를 실제 키로 통과하는 것임. 하나라도 「등록은 되는데 조용히 실패」하면 미완료임.

| # | 제공자 | 입력할 Base URL | 확인 사항 |
|---|---|---|---|
| A | Google Gemini (OpenAI 호환) | `https://generativelanguage.googleapis.com/v1beta/openai` | `/v1` 강제부가 없이 모델 목록 취득 → 피커 노출 → 대화 성공 |
| B | Hugging Face Router | `https://router.huggingface.co/v1` | 동일 |
| C | NVIDIA NIM | `https://integrate.api.nvidia.com/v1` | 하드코딩 목록이 아니라 **실제 계정에서 동작하는 모델**만 노출 |
| D | OpenRouter | `https://openrouter.ai/api/v1` | 동일 |
| E | Anthropic | `https://api.anthropic.com/v1` | 등록 시 비호환이면 **명시적 실패**. 조용한 통과 금지 |

### 휴리스틱이 아닌 것 (유지)

- `openai_compat_client.probe()` — 실제 HTTP 프로브임. 단 line 107의 **「목록은 됐으니 부분 성공으로 ok 반환」은 조용한 실패 경로이므로 제거 대상**임.

## 2. 설계 원칙

1. **등록 시점에 1회 실측하고, 결과를 저장한다.** 런타임에는 추정을 하지 않는다.
2. **추정이 필요하면 후보를 만들어 HTTP로 시도하고, 성공한 값을 확정값으로 되써 저장한다.**
3. **모르면 `unknown`이라고 말한다.** `True`로 낙관하지 않는다.
4. **제공자별 특수 분기를 늘리지 않는다.** NVIDIA 전용 경로가 늘어나는 방향은 목표에 정면으로 반한다.

## 3. 작업

### 작업 1 — Base URL 해석을 실측으로 (H1·H2 / 연번 4·5)

`iris/infrastructure/openai_compat_client.py`

`normalize_base_url()`의 무조건 `/v1` 부가를 제거하고, **후보 탐색 + 확정** 함수로 대체함.

```python
_VERSION_SEGMENTS = ("v1", "v1beta", "v1alpha", "v2", "openai", "api")

def base_url_candidates(raw: str) -> list[str]:
    """시도 순서대로 후보 반환. 첫 항목이 가장 유력함."""
    # 1. 공백·후행 슬래시 제거
    # 2. "/chat/completions"로 끝나면 해당 접미사 제거
    # 3. 마지막 세그먼트가 _VERSION_SEGMENTS에 속하면 [raw] (그대로 존중)
    # 4. 아니면 [raw + "/v1", raw]
```

```python
def resolve_base_url(raw, api_key, *, timeout=6.0) -> tuple[str, str, list[str], str]:
    """(확정 base_url, auth_style, models, detail). 실패 시 base_url == ""."""
    # 각 후보에 GET {cand}/models 시도 → 200이면 채택
    # 전 후보 /models 실패 시, 각 후보에 chat 스모크 1회 → 성공 후보 채택
    # 전부 실패 → ("", "", [], 마지막 오류)
```

**인증 헤더도 실측함** (연번 6 해소 경로). 기본은 `Authorization: Bearer <key>`이며, 401/403 응답 시 `x-api-key: <key>` + `anthropic-version: 2023-06-01`로 **1회만** 재시도함. 성공한 방식을 `auth_style`(`"bearer"` | `"x-api-key"`)로 반환하여 저장함.

> **선결 확인 (구현 전 반드시 실측할 것)**
> Anthropic은 `https://api.anthropic.com/v1`에 OpenAI 호환 `chat/completions`를 제공하나, `GET /v1/models`가 Bearer를 수용하는지 확인 필요함. 실제 키로 다음을 실행하여 결과에 따라 분기할 것.
> - **양쪽 다 Bearer로 통과** → 위 인증 폴백만으로 연번 6 해소됨. 별도 어댑터 불필요.
> - **`/models`만 `x-api-key` 요구** → 위 폴백이 그대로 처리함. 역시 어댑터 불필요.
> - **`chat/completions` 자체가 비호환** → 어댑터가 필요하므로 **구현 전에 보고하고 중단할 것.** 임의로 `anthropic_client.py`를 만들지 말 것.

`api_providers.py`의 `guess_base_url()`은 **제거**하고, 설정 화면의 프리셋 콤보로 대체함 (작업 4).

### 작업 2 — 도구지원 판정을 실측으로 (H3·H4·H5 / 연번 7)

`iris/infrastructure/api_model_meta.py`

`_NVIDIA_RULES`·`describe_api_model`의 이름 기반 분기를 **삭제**하고 3-상태 실측으로 대체함.

```python
ToolSupport = Literal["yes", "no", "unknown"]

def probe_tool_support(base_url, api_key, model, *, auth_style, timeout=15.0) -> ToolSupport:
    """tools 1건을 실은 max_tokens=1 chat 요청으로 판정."""
    # 200 → "yes"
    # 400 / 422 + 본문에 tool/function 언급 → "no"
    # 401 / 403 / 429 / 5xx / 타임아웃 → "unknown"
```

**판정 우선순위** (위가 우선):

1. `/models` 응답 메타 — OpenRouter `supported_parameters`에 `"tools"` 포함, HF `supports_tools` 등. 무료이며 정확함.
2. 캐시된 프로브 결과 (`ApiProvider.tool_support`).
3. **지연 프로브** — 사용자가 그 모델을 **처음 선택할 때** 1회 프로브하고 캐시. 등록 시 전 모델 프로브는 금지(100+ 모델에서 비용·시간 과다).
4. 위 전부 미확정이면 `"unknown"`.

`api_model_supports_tools()`는 현재 `bool`을 반환하며 호출부가 2곳임 (`main_window.py:991`, `_check_model_picker_tiers.py:50`). **계약을 3-상태로 바꾸고 호출부를 함께 고칠 것.** `unknown`은 피커에서 「도구 미확인」으로 표시하며, 도구 호출이 필요한 턴에서는 실행 전에 프로브를 1회 수행함.

`ApiModelMeta`의 `pros`/`cons`/`limit` 문구는 근거 없는 마케팅 문장이므로 **삭제**하고, 실측 가능한 것만 남김: `category`(제공자 `/models` 메타 또는 `unknown`), `tool_support`, `last_probe_detail`.

### 작업 3 — 하드코딩 모델 스냅샷 제거 (H6·H7 / 연번 8)

`_NVIDIA_FREE_ENDPOINT_MODELS`·`filter_nvidia_free_endpoint_models`·`is_nvidia_free_endpoint_model`·`is_nvidia_provider`·`nvidia_category`를 **전부 제거**함. 호출부는 `main_window.py:979-981`, `settings_dialog.py:584-591`, `model_picker_menu.py:324`임.

대체 동작: `/models`가 반환한 목록을 그대로 쓰되, **모델별 상태를 저장**하여 피커에서 구분함.

| 모델 상태 | 판정 근거 | 피커 표시 |
|---|---|---|
| `ok` | chat 또는 tools 프로브 성공 | 정상 노출 |
| `unverified` | 미프로브 | 정상 노출 (선택 시 프로브) |
| `unavailable` | 프로브가 4xx로 실패 (권한·엔드포인트 없음) | 비노출 또는 흐리게 + 사유 툴팁 |

이로써 NVIDIA 무료 엔드포인트 문제는 「하드코딩 목록 관리」가 아니라 「첫 선택 시 실패를 정확히 보고」로 해소됨. 분류기·비전 전용 모델(`nemoguard`, `content-safety`, `-vl-`)은 tools 프로브에서 `no`로 판정되므로 에이전트 경로에서 자동 제외됨.

> `filter_nvidia_free_endpoint_models`의 「교집합 0이면 전체 반환」 폴백은 **어떤 형태로도 재도입 금지**임. 존재하지 않는 모델을 사용자에게 제시하는 경로임.

## 7. 참고 — `/v1`이란

URL 경로의 **API 버전 세그먼트**임. OpenAI REST API가 `https://api.openai.com/v1/chat/completions` 형태를 쓰면서 사실상 표준이 되었고, 다수 제공자가 이를 모방하여 「OpenAI 호환」을 표방함.

문제는 **모든 제공자가 `/v1`을 쓰지는 않는다**는 점임.

| 제공자 | 실제 경로 | 현행 `normalize_base_url` 결과 |
|---|---|---|
| OpenAI | `/v1/chat/completions` | 정상 |
| Gemini | `/v1beta/openai/chat/completions` | `/v1beta/openai/v1/...` → **404** |
| Groq | `/openai/v1/chat/completions` | 루트 입력 시 `/v1`만 붙어 **404** |
| Anthropic | `/v1/messages` (경로·헤더 규격 상이) | 경로는 맞으나 **본문 규격 불일치** |
| Azure OpenAI | `/openai/deployments/<name>/chat/completions?api-version=…` | **구조 자체가 다름** |

연번 5는 바로 이것임. `normalize_base_url()`이 예외 없이 `/v1`을 덧붙이므로, 이미 `/v1beta/openai`까지 정확히 입력한 사용자의 URL을 코드가 망가뜨림. 그래서 작업 1은 「`/v1`을 붙일지 말지」를 문자열 규칙으로 판단하지 않고, **후보를 만들어 실제로 `GET {후보}/models`를 때려보고 200이 나오는 것을 채택**하는 방식으로 바꿈.
