# Prompt: 답 끝 고정 문장을 빼고 모델이 답한다

기준: `docs/code-review/답변끝-고정문장-원인.md`.

```text
Context:
- 채팅·IDE 답은 _on_chat_finished → _gate_chat_completion 에서 바뀐 뒤 저장된다.
- classify_turn / wants_iris_structure / 완료 단어가 맞으면 앱이 문장을 지우거나,
  답 전체·한 문장·끝줄을 정해 둔 글로 바꾼다.
- 같은 글이 프롬프트에도 있다. 「없다고만 해라」「이 발췌에 있는 문장만 써라」
  「정확히 이렇게만 답하라」.
- 검색이 실패하면 모델을 부르지 않고 「검색을 하지 못했습니다」만 남긴다.
- 이미지·코드 단어가 있으면 모델 전에 「열린 파일이 없습니다」 같은 글로 턴을 닫는다.

Goal:
1) 모델이 쓴 답을 저장·화면에 그대로 둔다.
   끝줄 추가, 문장 치환, 답 전체 교체를 하지 않는다.
2) 그 문장을 상황·키워드로 고르는 분기는 답 출력에 쓰지 않는다.
   새 키워드 목록이나 다른 고정 문장으로 바꾸지 않는다.
3) 위키 발췌, 소스 노트, 검색 결과, 검색 실패 이유는 사실로만 모델 맥락에 넣는다.
   특정 문장을 말하라고 시키지 않는다. 실패해도 모델을 부른다.
4) 코드 블록을 IDE에 열고 실행하는 동작은 남긴다.
   그 다음에 붙이던 아이리스 말풍선(열었습니다, 터미널 실행, 준비되지 않았습니다)은 넣지 않는다.
   실행 결과 도구 블록은 남긴다.
5) 「작성|코드」로 채팅 턴을 가로채 묻거나 완료 문장으로 바꾸는 이미지 파이프는
   채팅에서 타지 않는다. 파일 쓰기는 project.write_image_code 도구가 맡는다.

Constraints:
- 휴리스틱을 더 정교하게 만들지 않는다. 문장 게이트를 다른 문장 게이트로 교체하지 않는다.
- 검색·노트 조회 자체는 지우지 않는다. 모델이 판단할 사실이다.
- 위키 따라가기(turn_followthrough)의 목표 판별은 그대로 둔다. 답 문장 교체만 뺀다.

Interface:
- _gate_chat_completion: 인자 텍스트를 그대로 반환.
- settle_grounded_answer, settle_wiki_claim, settle_completion_claim: 모델 텍스트를 그대로 반환.
  문장 삭제, 「발췌에 없다.」「노트에 없다.」「검색 결과에 없다.」
  「이번 턴 도구 결과: … · ok 없음」「노트는 그대로다」
  「채팅에만 있고 파일은 만들지 않았다」를 넣지 않는다.
- 웹 검색 실패: _pending_web_evidence 에 상태·오류·검색어만 넣고 launch().
- 위키·코드 노트 머리말과 0건 블록: 발췌 또는 0건이라는 사실만. 「이라고만 해라」 삭제.
- format_evidence: 결과·오류만. 「덧붙이지 마라」「이라고만 알려라」 삭제.
- routine build_run_messages: 웹 도구가 없다는 사실만. 정해 둔 한 문장을 답하라 삭제.
- _handle_image_code_pipe: False. 채팅은 모델로 간다.
- _try_reveal_local_vibe_code: 열기·쓰기·project.run 과 도구 블록은 유지.
  append_message_instant 로 고정 문장을 추가하지 않는다.

검증:
.venv\Scripts\python.exe -m iris.knowledge.answer_grounding
.venv\Scripts\python.exe -m iris.knowledge.wiki_claim
.venv\Scripts\python.exe -m iris.knowledge.wiki_note_index
.venv\Scripts\python.exe -m iris.knowledge.code_note_prompt
.venv\Scripts\python.exe -m iris.runtime.routine_search
.venv\Scripts\python.exe -m iris.runtime.routine_runner
.venv\Scripts\python.exe -m iris.ui._check_file_write_claim
.venv\Scripts\python.exe -m iris.ui._check_ide_request_tools
.venv\Scripts\python.exe -m unittest tests.test_routine_search tests.test_iris_routines
```
