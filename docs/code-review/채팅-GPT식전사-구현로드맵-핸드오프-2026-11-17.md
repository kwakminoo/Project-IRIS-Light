## 0. 고정 결정 (다시 조사하지 말 것)

| 항목 | 결정 |
|---|---|
| UI 툴킷 | **PyQt6 유지**. Electron/Tauri/언어 교체 안 함 |
| 막힌 곳 | PyQt6가 아니라 **`QTextEdit` 채팅 로그** |
| 목표 데이터 | `Message = list[Part]` (text / writing / code / tool / image / app / citation …) |
| 목표 호스트 | **H1 WebEngine 전사 (B0 승).** H2는 탈락. **H3 QTextEdit+커스텀 object 비추천** |
| 최소구현 바 | 쓰지 않음. matrix 색칠·슬롯 카드만으로 「GPT식 완성」이라 하지 않음 |
| App Host 슬롯 | T5에서 인라인 AppPart로 옮김. 그 전 빈 HTML 게이트는 임시 가드만 |

## 2. 병행 가능 / 직렬

| 관계 | 내용 |
|---|---|
| 직렬 | B0 → T0 → T1 → T2 → (T3·T4는 T2 후 병렬 가능) → T5 → T6 → T7 → T8 → T9 → T10 |
| T3∥T4 | T2 green 후 code/writing 독립 구현 가능. 공유 Transcript API만 맞춤 |
| T5 전 | App Host 빈 HTML 가드는 임시. T5가 정본 |
| T6 | T2 없이도 파서만 짤 수 있으나, **랜딩은 T2 후**에만 의미 있음 |

## 3. 금지

| 금지 | 이유 |
|---|---|
| QTextEdit sanitize 확장으로 GPT 패리티 선언 | 천장 |
| H3를 기본 경로로 | 불안정 |
| PySide6/Electron을 이 로드맵에 끼워 넣기 | GPT와 무관·비용 과다 |
| T2 없이 T3–T5를 옛 로그에 욱여넣기 | 다시 슬롯·HTML blob으로 회귀 |
| 구현 서브에이전트 하나에 T0–T10 몰아넣기 | `implement-via-subagents`: 단위별 fresh |
