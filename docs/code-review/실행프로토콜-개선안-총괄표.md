## 1. 아키텍처 요약

| 계층 | 역할 | 파일 |
|------|------|------|
| 오케스트레이션 | Core 10단계 + Optional 설치·검증·스트림 | `setup_protocol.py` (`SetupProtocol`) |
| 워커 | QThread + `needs_user` 게이트 | `setup_protocol_worker.py` |
| UI | 목록·진행률·NeedsUser 카드·하단 로그 | `setup_wizard.py` |
