## 0. 사전 조건

| 항목 | 기준 |
|------|------|
| OS | Windows 10/11 64bit |
| 네트워크 | 인터넷 연결 (클라우드 모델·도구 호출) |
| 시간 | 전체 **25–40분** (첫 설치·모델 pull 포함) |
| 기록 | 단계마다 Pass/Fail · 소요시간 · 스크린샷 1장(선택) |

### 0.1 코드서명 / SmartScreen (C9)

`IRIS-Setup.exe`는 현재 **Authenticode 미서명**이다 (`docs/code-signing.md`).

| 증상 | 정직 고지 · 우회 |
|------|------------------|
| SmartScreen 「Windows에서 PC 보호」 | **추가 정보 → 실행** |
| 브라우저 다운로드 경고 | GitHub Releases 공식 URL만 사용 |
| 기업망 EXE 차단 | 소스 설치(방법 B: `setup.bat`)로 대체 가능 |

검증관에게 “서명 없음”을 숨기지 말 것. 서명 후에만 SmartScreen 경고 소멸을 기대한다.

실패 시: 설치 폴더 `setup-log.txt` · `%LOCALAPPDATA%\iris-light\launcher.log` 첨부.

## 4. 시나리오 D — 프롬프트 → Hermes → 응답 (핵심 100점)

| # | 조작 | 기대 결과 | 소요(안) | ☐ |
|:-:|------|-----------|:--------:|:--:|
| D1 | 채팅 입력창 클릭 | 포커스·커서 표시 | 10초 | |
| D2 | `안녕. 한 문장으로 자기소개해 줘.` 입력 후 전송 | 사용자 버블 표시 · 스트리밍/완료 응답 1회 | 30–90초 | |
| D3 | (선택) `오늘 날짜만 알려줘.` | 도구/모델 응답이 끊기지 않고 완료 | 30–90초 | |
| D4 | 응답 중 **중지** 버튼(있으면) 1회 | 생성 중단 · UI 복귀 (크래시 없음) | 20초 | |

**Pass 기준:** D1–D2 필수. Hermes/Ollama 미기동이면 C로 돌아가 재시도 후 D 재실행.

## 5. 시나리오 E — 회귀 보조 (개발자 스모크, 선택)

사람 클릭 검증이 끝난 뒤, 동일 PC에서:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_core_smoke.ps1
```

기대: 핵심 체크 exit code 0. 상세는 `docs/검증/core-smoke.md`.
