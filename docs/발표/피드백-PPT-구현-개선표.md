## 2. B. 코드 · 기능 · 문서 구현 — IRIS 현황 대조

### 2.3 구현하지 않아도 되는 것 (YAGNI)

| 항목 | 이유 |
|------|------|
| PyQt6 → PySide6 실제 전환 | `LICENSE.md` §5가 일정상 비권장. **가이드 문서만**으로 유연성 점수 충족 가능 |
| 새 대형 기능 추가 | 피드백은 검증·문서·OSS 프레임. 기능 카탈로그 확장은 발표 톤과 충돌 |
| frozen 풀번들 exe 회귀 | thin launcher(`dist/IRIS.exe` → `.venv\pythonw -m iris`) 계약 유지 |
