## 1. 한 줄 요지

**오늘의 발표는 “잘 만든 시스템/제품 소개”에 가깝고, 2차에서 필요한 것은 “개발자가 가져다 쓸 수 있는 오픈소스 런타임”으로의 재프레이밍이다.**  
기능테스트·라이선스는 만점(100) 전제, 발표는 평가지 항목에 맞춰 스스로 95점 설계, 시연은 조작 없이 사전 편집 클립으로 흐르게 할 것.

## 3. 대회 성격·평가 구조·양식

### 3.1 대회 성격

| 항목 | 내용 |
|------|------|
| 정식 명칭 | 2026 오픈소스 개발자대회 (20주년) |
| 슬로건 | 「우리의 코드 한 줄이, AI 시대 지능을 키운다」 |
| 주최/주관 | 과기정통부 / NIPA 등 (운영: 한국오픈소스협회 사무국) |
| 목적 | 우수 오픈소스 발굴, 개방·협업 생태계, 개발 인재 양성 |
| 부문 | 자유과제 / 지정과제(기업) / 사회문제해결 |
| IRIS 적합 부문 | **자유과제**(AI·데스크톱 에이전트 런타임) — 제품 경진이 아님 |
| 핵심 메시지 | “파는 제품”이 아니라 **공개된 소스·재사용·기여 가능한 프로젝트** |

### 3.2 평가 구조 (공개 범위)

| 단계 | 배점·성격 | 평가 자료 | 비고 |
|------|-----------|-----------|------|
| 1차 서면 | **30점** | 개발(결과)보고서, 소스코드, 시연 동영상 | 통과 완료 |
| 출품작 검증 | 별도 검증(점수 반영·통과 성격) | 기능테스트, 라이선스 충돌·위반 검증(온라인 툴) | **만점급 준비 필수** |
| 2차 발표·종합 | **70점** | 발표(PPT 등) + 종합평가 | 승패 구간 |
| 항목별 세부 배점 | 공고에 미공개 | 오리엔테이션·대회 가이드에서 공지 | 멘토/사무국 자료 재확인 |

※ 공개 자료상 **별도 ‘가산점’ 항목 표는 확인되지 않음**. 실질 가산은 검증 만점·오픈소스성 어필·멘토링 반영 완성도로 해석하는 것이 타당함.

## 7. 발표 스토리라인 권장(안)

| 분 | 슬라이드 목적 | 말할 한 줄 |
|----|---------------|------------|
| 0–1 | 정의 | IRIS는 제품이 아니라 **오픈소스 데스크톱 에이전트 런타임**이다. |
| 1–2 | 문제(개발자) | PC에서 도구를 쓰는 에이전트를 조립하는 비용·파편화가 크다. |
| 2–3 | 해결 경계 | UI·세션·권한·스트리밍은 IRIS, 추론·도구는 Ollama/Hermes에 위임. |
| 3–4 | 오픈소스성 | GPL, 고지, 확장점(스킬/MCP), 남이 기여하는 길. |
| 4–5 | 확장·지속 | 코어 불변 + 가이드라인(UI 전환 포함). |
| 5–7 | 시연 클립 | 설치→에이전트→IDE companion (조작 없이). |
| 7–8 | 검증·로드맵 | 기능/라이선스 준비, 커뮤니티 스킬·마켓. |
