| 항목 | 내용 |
|---|---|
| 문서 번호 | IRIS-PPT-2026-1013 |
| 작성일 | 2026-10-13 |
| 관련 | 이호진 교수님 피드백(2026-09-23), [2025 우수작 정보집](https://www.kossa.kr/materials/2025/ossp/ebook/index.html), `IRIS-2차발표-1차안.pptx` |

근거는 저장소에 있는 전사·총괄표·1차안 대본, `docs/domain.md`, `docs/guides/extending-iris.md`, `LICENSE.md`, `docs/검증/core-smoke.md`, 정보집 본문 60쪽이다. 정보집에 심사 배점 10항목 원표는 없다. 아래 「심사 축」은 교수 발언을 복원한 것이며 공식 배점표가 아니다.

---

## 1. 결론

발표는 **개발자가 포크해 자기 에이전트를 얹는 데스크톱 런타임**으로 간다. 2025년 대상·금상도 완성 앱이 아니라 라이브러리, 프레임워크, 업스트림 기여, 교육 문서였다. 화면은 이미 만든 12장 1차안(흰 종이, 장당 주장 1개)을 유지하고, 각 장에 경로·명령·문서 이름을 한 줄씩 넣어 “가져다 쓰는 자리”를 증명한다. 기능 목록과 구독 비용 이야기는 넣지 않는다.

---

## 2. 교수님이 제시한 방향

교수님은 장 번호가 적힌 PPT 파일을 주지 않았다. 약 54분 피드백에서 준 것은 **평가지에 맞춰 스스로 95점을 설계하는 오픈소스 발표**다. 1차안 12장은 그 말을 WelsonJS식 흐름(정의 → 제약 → 남이 쓰는 자리 → 라이선스 → 기여)으로 옮긴 초안이다.

### 2.1 방향 한 장

```text
심사위원 (서류를 읽으며 듣는다, 목소리는 배경)
        │
        ▼
평가지 약 10항목 × 0–10점 ── 스스로 채점, 목표 95
        │
        ├─ 만점 전제 ─ 기능테스트(클릭 단위) · 라이선스(충돌 0)
        │
        └─ 발표 70점 쪽
              개발자 청중
              오픈소스 = 소스가 열려 있고 남에게 도움이 됨
              코어는 고정, 확장은 가이드
              사람+AI가 읽는 문서
              학생 팀, 현실 사양
              본문 7–8분, 영상은 재생만, 흑백 인쇄에도 읽힘
```

### 2.2 교수 항목과 넣을 내용

| No | 교수 요지 | 슬라이드에 넣을 것 | IRIS에서 쓸 근거 |
|:--:|---|---|---|
| 1 | 항목 ~10개에 맞춰 자평. 금상 ~85, 대상 ~95 | 장마다 심사 축 1개. 점수표는 슬라이드에 올리지 않고 발표자 노트에 둔다 | 본 문서 §6 |
| 2 | 영상 중 마우스 금지. 30초 클립. 10분 중 본문 7–8분 | 설치 / 입력→응답 / IDE 동반, 각 30초. 재생만 | 1차안 10장 노트 |

### 3.2 공통점

| 보는 것 | 수상작에서 반복된 모습 |
|---|---|
| 정체 | 상위권은 「남이 import / 설치 / 포팅 / 기여하는 단위」다 |
| 한 줄 | 사용자 효용이 아니라 **개발 작업이 줄어드는 지점** |
| 공개 | GitHub URL이 표에 있다. 문서·교육자료·npm까지 있으면 더 읽힌다 |
| 역할 | 총괄과 구현이 나뉘어 있다 |
| 검증 | 기능이 재현되고, 라이선스 충돌이 없다. 격려상 팀은 라이선스 검증을 역할로 적었다 |
| 생태계 | 금상 일반은 새 앱이 아니라 Zephyr 업스트림과 교육 문서다 |
| AI | AI 과제는 많다. 대상은 AI 챗봇이 아니다. 학생 금상은 Q&A **프레임워크**다 |

챗봇·에이전트 화면을 전면에 둔 출품(금융 챗봇, 비주얼 에이전트 플랫폼)은 지정과제 동상·우수작에 있다. 같은 설명을 하면 IRIS는 그 무리로 읽힌다.

### 3.3 이 대회 발표에 들어가야 하는 것

1. 한 줄 정의. 누구의 어떤 개발 작업을 대신하는가.
2. 소스 위치. 저장소 주소.
3. 가져다 쓰는 절차. 설치가 아니라 **확장 절차**.
4. 라이선스를 고른 이유와 충돌이 없다는 말.
5. 기능이 클릭 단위로 재현된다는 말. 시연은 그 절차의 짧은 증거.
6. 코어를 건드리지 않고 잇는 자리. 또는 업스트림에 되돌린 기여.
7. 다음 사람이 읽을 문서.

## 4. 1차안을 어디에 고칠지

1차안 12장의 순서는 교수 방향과 2025 상위권 흐름에 맞다. 장 수를 늘리지 않는다. 비어 있는 자리는 **절차의 이름**이다.

| 장 | 1차안 | 유지 | 보강 |
|:--:|---|---|---|
| 1 | IRIS, Desktop AI Agent Runtime | 유지 | 부제 아래 저장소 주소 |
| 2 | 포크·확장·성취 | 유지 | |
| 3 | 조립이 막힌다 | 유지 | |
| 4 | IRIS / Ollama / Hermes 경계 | 유지 | 「웹검색·셸·파일은 다시 만들지 않음」은 이미 있음 |
| 5 | CONTRIBUTING, 스킬, Good first issue | 유지 | 스킬 추가 경로 1줄 |
| 6 | CORE / EXTENSION | 유지 | `run_core_smoke.ps1` |
| 7 | domain·IA / agent-readable | 유지 | |
| 8 | GPL 이유, UI 전환 가이드 | 유지 | 전환은 아직 문서만 |
| 9 | 일반 PC 사양 | 유지 | 「재현 조건」으로 한 줄. 사양표가 본문이 되지 않게 |
| 10 | 클립 3개 | 유지 | 현장 대본은 1차안 노트. 3분 홍보 대본의 구독 문장은 쓰지 않음 |
| 11 | 기능·라이선스 | 유지 | 시나리오서 파일명 |
| 12 | 교육용 에이전트, IDE 동반 | 유지 | |

3분 데모 대본(`docs/demo-video-script.md`)은 README용이고 청중이 「파이썬을 처음 깔아보는 사람」이다. 2차 현장 문장은 1차안 `notes()`를 쓴다.

## 5. 장별 내용과 말할 문장

말하는 시간은 장당 약 30초. 10장은 클립 90초. 합이 약 7분이다. 10분 슬롯에서 7분 전후에 말을 멈추고 남은 시간은 질문으로 둔다.

| 장 | 화면 한 줄 | 말할 문장 | 근거 |
|:--:|---|---|---|
| 1 | IRIS는 데스크톱 AI 에이전트 런타임입니다 | 세션과 화면은 IRIS가 맡고, 추론은 Ollama, 도구는 Hermes가 맡습니다. 저장소는 github.com/kwakminoo/Project-IRIS-Light 입니다. | `domain.md` §1, 1차안 표지 노트 |
| 2 | 쓰는 사람은 개발자입니다 | 가져가서, 스킬과 MCP를 얹고, 자기 에이전트를 만듭니다. | 1차안 2장 |
| 3 | 막히는 지점은 조립입니다 | PC 위에서 프롬프트 화면, 모델, 도구, 세션이 따로 있습니다. | 1차안 3장. 요금 이야기는 빼기 |
| 4 | IRIS가 고정하는 자리 | IRIS는 세션, 권한, 스트리밍 화면입니다. 검색과 셸과 파일은 다시 만들지 않습니다. | Gateway는 어댑터. Ollama `:11434`, Hermes `:8642` |
| 5 | 남이 가져가는 길 | 기여 문서는 `CONTRIBUTING.md`입니다. 스킬은 `integrations/hermes-skills/`에 넣고 코어 diff는 0으로 둡니다. 첫 이슈는 Good first issue입니다. | `extending-iris.md` §2 |
| 6 | 코어는 고정합니다 | 코어는 세션·게이트웨이·권한입니다. 확장은 스킬, MCP, IDE입니다. 회귀는 `scripts/run_core_smoke.ps1` 한 번입니다. | `core-smoke.md` S1–S5 |
| 7 | 사람과 AI가 같이 읽습니다 | 구조 계약은 `docs/domain.md`와 `docs/ia/IA.md`입니다. 에이전트용 헤더 계약은 `docs/guides/agent-readable-docs.md`입니다. | 교수 No.6, 대회 슬로건 |

| IDE 동반 30초 | IRIS IDE와 Iris가 8:2로 붙음 | 확장 예시 하나 |

메일, 캘린더, 위키, 모니터 목록은 이 12장에 넣지 않는다. 질의에서 물으면 워크스페이스는 HUD 안의 선택 확장이며 코어는 게이트웨이라고 답한다.

## 9. 발표 대본

10분 슬롯이다. 말은 약 7분에 멈춘다. 10장은 클립 90초이고, 재생 중에는 말하지 않는다. 2·3장 문장은 §5 표 이후 맞춘 것이다. 요금, 메일, 캘린더, 위키는 말하지 않는다.

**1장. 표지** (약 30초)

IRIS는 데스크톱 AI 에이전트 런타임입니다. 세션과 화면은 IRIS가 맡고, 추론은 Ollama, 도구는 Hermes가 맡습니다. 저장소는 github.com/kwakminoo/Project-IRIS-Light 입니다.

**2장. 청중** (약 30초)

쓰는 사람은 개발자입니다. 대학생과 처음 만드는 개발자입니다. 가져가서 스킬, MCP, 화면을 자기 에이전트에 맞춥니다.

**3장. 문제** (약 30초)

로컬 에이전트는 터미널, 텔레그램, 디스코드에서 다루고, 모델과 도구와 화면은 포트로만 이어집니다. 런타임과 게이트웨이가 어긋나면 그 연결이 매번 끊깁니다.

**4장. 경계** (약 30초)

IRIS는 세션, 권한, 스트리밍 화면, 시작 프로토콜을 고정합니다. 검색과 셸과 파일은 다시 만들지 않습니다. 모델은 Ollama 11434, 도구는 Hermes 8642입니다.

**5장. 가져가는 길** (약 30초)

기여 문서는 CONTRIBUTING.md입니다. 스킬은 integrations/hermes-skills/에 넣고, 코어 diff는 0으로 둡니다. 첫 이슈는 Good first issue입니다.

**6장. 코어** (약 30초)

코어는 세션, 게이트웨이, 권한입니다. 확장은 스킬, MCP, IDE입니다. 회귀는 scripts/run_core_smoke.ps1 한 번입니다.

**7장. 문서** (약 30초)

구조 계약은 docs/domain.md와 docs/ia/IA.md입니다. 에이전트용 헤더 계약은 docs/guides/agent-readable-docs.md입니다.

**8장. 라이선스** (약 30초)

UI가 PyQt6라 결합 저작물은 GPL-3.0-or-later입니다. 다른 UI로 가는 절차는 docs/guides/ui-toolkit-migration.md에 있습니다. 툴킷 전환은 아직 하지 않았습니다.

**9장. 재현** (약 30초)

학생 팀입니다. Windows 10과 11, 메모리 최소 8GB, 권장 16GB입니다. GPU는 필요 없습니다. 클라우드 모델이 기본입니다.

**10장. 클립** (90초, 말은 한 줄)

설치, 입력에서 응답, IDE 동반. 각 30초입니다. 마우스는 잡지 않습니다.

**11장. 검증** (약 30초)

기능은 설치, 입력, 통신, 응답이 기능테스트-시나리오서.md에 있습니다. 라이선스 내부 스캔은 충돌 0입니다. 대회 온라인 툴 리포트는 검증 기간에 붙입니다.

**12장. 맺음** (약 20초)

이 런타임 위에 교육용 에이전트와 IDE 동반 코딩을 만들 수 있습니다. 주소만 남기고 말을 멈춥니다. 남은 시간은 질문입니다.
