**고정(📌) 창 감시가 실제로 화면을 본다**
- 고정한 창을 1초마다 확인하고, 화면이 바뀌면 그때 로컬 비전 모델(qwen2.5vl:3b)로 분석한다. 화면이 그대로여도 60초마다 한 번은 다시 본다.
- 앱을 켜면 이미 고정된 창을 바로 분석한다. Ollama가 아직 뜨는 중이면 켠 뒤 2분 동안 10초마다 다시 시도한다.
- 닫힌 고정 창도 카드로 보여 줘서 고정을 풀 수 있다.
- 채팅으로 "고정한 창 어때?"라고 물으면 감시 결과로 바로 답한다. 해제·열기 같은 요청은 가로채지 않는다.

**업무 학습 — 전부 로컬 (ShowUI-Aloha 대체)**
- 시연을 녹화해 스킬(단계 + 바꿔 넣을 칸)로 만들고, 채팅으로 부르면 로컬 모델로 실행한다.

- 비밀번호 칸이나 "글자 저장 안 함" 설정에서도 키 코드·원본 키·입력창 글자가 남던 문제를 고쳤다. 입력한 뒤 Alt+Tab 하는 경우도 포함한다.
- Shift+Enter·Shift+Tab을 녹화할 때 Shift가 빠지던 문제를 고쳤다. 이름 없는 키(`vkXX`) 재생도 고쳤다.

- 스킬 등록 창에서 긴 글자 안에 있는 칸이 사라지던 문제를 고쳤다.

- Hermes 설치 때 Python 범위가 비어 어떤 Python도 통과하지 못하던 경우를 고쳤다.

## A-2. 자동 설치 · 환경 구성

> "GUI로 초보자도 쓸 수 있게 한 건 좋은데 설치가 어려울 것 같다"

| 파일 | 역할 |
|------|------|
| **`setup.bat`** | **더블클릭 진입점.** ExecutionPolicy 우회 포함 — 터미널을 열 필요가 없습니다 |
| `setup.ps1` | 자동 설치 본체 (Windows) |
| `setup.sh` | Linux / macOS 동등 기능 |
| `.env.example` | 환경 설정 템플릿 — **지금까지 없던 파일** |

6단계이고 **각 단계가 실패하면 구체적인 해결 명령을 화면에 출력**합니다.
Python 탐색 → venv → pip → 의존성 → `.env` → **PyQt6 import 검증**.
옵션: `-Run` / `-Voice` / `-Recreate`.

> `.env.example` 이 없던 게 실제 함정이었습니다. 기존 `.env` 가 주석으로
> "템플릿: .env.example" 이라고 안내하는데 정작 그 파일이 저장소에 없었습니다.

**검증**: `setup.ps1` 과 `setup.bat` 모두 실제로 끝까지 실행해 통과 확인.
`setup.sh` 는 `bash -n` 문법 검사만 했고 Linux 실행은 확인하지 못했습니다.

> 참고로 발견한 것 — **Windows PowerShell 5.1 은 BOM 없는 UTF-8 `.ps1` 을 cp949 로 읽어서**
> 한글이 든 스크립트가 파싱 에러를 냅니다. `setup.ps1` 에는 BOM 을 넣어 해결했는데,
> 기존 `scripts/setup_voice_runtime.ps1` 도 BOM 이 없어 같은 문제가 날 수 있습니다.

## 목적
설정 → 시작 프로토콜 「검사」/「다시 설정」은 정상인데, 채팅을 보내면 `Hermes HTTP 401 Unauthorized`가 나던 문제를 시작 프로토콜에서 재발하지 않게 고칩니다.

## 원인
- 검사는 GET `/health`·`/v1/models`만 봐서 통과하고, 실제 채팅 POST `/v1/chat/completions`만 Bearer/업스트림 401이 났습니다.
- `/api/tags`에 클라우드 스텁(`*:cloud`, `*-cloud`)만 있어도 “모델 준비됨”으로 통과했습니다. 미로그인이면 채팅이 401입니다.

## 변경 요약
- **검사(`verify_core`)**가 채팅과 같은 POST로 401을 탐지합니다.
- 검사는 **최소 로컬 모델 유무**와 **Ollama 클라우드 로그인**을 함께 보여 줍니다.
- **로그인되어 있고 최소 모델이 없으면** 다운로드 없이 클라우드를 쓰는 것을 권장하는 안내창을 띄웁니다.
- 시작 프로토콜 Ollama 단계에서 **「로그인」**과 **「최소 모델 설치」** 버튼을 제공합니다. 둘 중 하나만 하면 됩니다.
- Core smoke가 401이면 API 키를 다시 맞추고 gateway를 재기동합니다.
