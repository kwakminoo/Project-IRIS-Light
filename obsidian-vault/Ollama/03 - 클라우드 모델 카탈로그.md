# Ollama 클라우드 모델 카탈로그 (기능·강점)

> Source: https://ollama.com/api/tags · https://ollama.com/library/<model> · https://docs.ollama.com/cloud
> 정리일: 2026-07-21
> 수집 방법: `ollama.com/api/tags`(카탈로그) + `/api/show`의 `capabilities`·컨텍스트·파라미터 + 각 모델 라이브러리 페이지 공식 설명

Ollama Cloud는 다운로드 없이 대형 오픈 모델을 원격에서 실행합니다. Iris Light는 이 카탈로그에서 **도구 호출(tool-calling) 지원 모델만** 목록에 표시합니다.

## capabilities 범례

| 플래그 | 의미(Iris 관점) |
|--------|------------------|
| `completion` | 텍스트 생성·대화 (기본) |
| `tools` | 도구 호출(함수 호출)·에이전트 — **웹검색·이미지생성 자동 호출에 필수** |
| `thinking` | 추론(reasoning) 모드 — thinking 스트림 표시 |
| `vision` | 이미지 분석(멀티모달 입력) |

## 모델별 상세

### Google — Gemma 4
- **`gemma4:31b`** · 이미지·도구·추론 지원 · 256K
- 공식: "각 크기에서 프런티어급 성능. 추론·에이전트 워크플로·코딩·멀티모달 이해에 적합."
- 강점: 상대적으로 가벼우면서 **이미지 분석 + 코딩 + 대화**를 두루 커버. 로컬(`gemma4:26b`)과 계열 동일.

### Alibaba — Qwen 3.5
- **`qwen3.5:397b`** · 이미지·도구·추론 지원 · 256K · MoE
- 공식: "탁월한 유용성과 성능의 오픈소스 멀티모달 모델 패밀리."
- 강점: **201개 언어**, 통합 비전-언어, 코딩/에이전트/시각이해 벤치 전반 상위. Iris에서 다국어·멀티모달 작업에 우선 추천.

### DeepSeek — V4
- **`deepseek-v4-flash`** · 도구·추론 · **1M 컨텍스트** · MoE(13B 활성/284B 총)
  - 초장문 문서·코드베이스 분석에 유리, 효율적 추론.
- **`deepseek-v4-pro`** · 도구·추론 · 512K · MoE(~1.6T)
  - 프런티어급, **3가지 추론 모드** 제공. 어려운 추론·합성 과제.

### Z.ai — GLM 5
- **`glm-5.1`** · 도구·추론 · 198K · 공식: "에이전틱 엔지니어링 플래그십, 코딩 대폭 강화(SWE-Bench Pro SOTA)."
- **`glm-5.2`** · 도구·추론 · **1M** · 공식: "장기 과제(long-horizon) 시대의 플래그십."
- 강점: **코딩·에이전트** 중심. 장기 작업엔 5.2(1M).

### OpenAI — gpt-oss
- **`gpt-oss:20b`** / **`gpt-oss:120b`** · 도구·추론 · 128K
- 공식: "강력한 추론·에이전트·다목적 개발용 오픈웨이트."
- 강점: 함수 호출·웹브라우징·파이썬 툴·구조화 출력 등 **에이전트 네이티브**, chain-of-thought 완전 공개, reasoning effort(low/medium/high) 조절. Apache 2.0. 20b는 저지연용.

### Moonshot AI — Kimi K2
- **`kimi-k2.5`** · 이미지·도구·추론 · 256K · 네이티브 멀티모달 에이전트(instant/thinking).
- **`kimi-k2.6`** · 이미지·도구·추론 · 256K · 장기 코딩·자율 실행·스웜 오케스트레이션.
- **`kimi-k2.7-code`** · 이미지·도구·추론 · 256K · **코딩 특화**(k2.6 기반), thinking 토큰 ~30% 절감.
- 강점: 1T급 초대형, **장기 코딩·에이전트** + 멀티모달.

### MiniMax
- **`minimax-m2.5`** · 도구·추론 · 192K · 실무 생산성·코딩.
- **`minimax-m2.7`** · 도구·추론 · 192K · 코딩·에이전트·전문 생산성.
- **`minimax-m3`** · 이미지·도구·추론 · 512K(공식 페이지 1M 표기) · **코딩·에이전트 프런티어 + 네이티브 멀티모달**.

### Mistral
- **`mistral-large-3:675b`** · 이미지·도구 · 256K · MoE
- 공식: "프로덕션·엔터프라이즈용 범용 멀티모달 MoE."
- 참고: 이 모델은 `thinking`(추론 모드) 플래그가 **없음** — 일반 대화·도구·이미지 중심.

### NVIDIA — Nemotron 3
- **`nemotron-3-nano:30b`** · 도구·추론 · 256K · 효율적 경량 에이전트 모델.
- **`nemotron-3-super`** · 도구·추론 · 256K · 120B MoE(12B 활성) — 효율 대비 정확도, 멀티에이전트.
- **`nemotron-3-ultra`** · 도구·추론 · 256K · 고처리량 추론·장기 에이전트 워크플로.

## Iris Light 관점 정리

- **도구 필터**: Iris 모델 목록은 `capabilities`에 `tools`가 있는 모델만 노출합니다(`iris/infrastructure/ollama_client.py`의 `model_supports_tools`). 위 18종은 모두 `tools` 지원.
- **웹검색·이미지생성 자동 호출**: 헤르메스 게이트웨이 경유 시, `tools` 지원 모델이면 사용자의 자연어 요청에 따라 `web_search` 등을 스스로 호출합니다.
- **용도별 추천**
  - 이미지 분석 필요 → `gemma4:31b`, `qwen3.5:397b`, `kimi-k2.*`, `minimax-m3`, `mistral-large-3`
  - 코딩 중심 → `glm-5.1/5.2`, `kimi-k2.7-code`, `qwen3.5:397b`, `minimax-m2.7`
  - 초장문 컨텍스트 → `deepseek-v4-flash`(1M), `glm-5.2`(1M), `minimax-m3`
  - 저지연·가벼움 → `gpt-oss:20b`, `nemotron-3-nano:30b`, `gemma4:31b`

## 은퇴(retirement) 참고

Ollama는 신모델 출시 시 구형 클라우드 모델을 순차 은퇴합니다(로컬 모델은 영향 없음). 예정 목록은 https://docs.ollama.com/cloud 의 "Upcoming retirements" 표 참고 — 예: `gemma3:*` → `gemma4:31b`, `qwen3-coder:480b` → `qwen3.5:397b`, `glm-5` → `glm-5.2`.
