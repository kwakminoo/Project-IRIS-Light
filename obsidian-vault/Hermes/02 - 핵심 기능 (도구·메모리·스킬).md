## 1. 도구 (Tools) & Toolsets

Hermes는 **60+ 빌트인 도구**를 **toolset** 단위로 켜고 끕니다.

```bash
hermes chat --toolsets "web,terminal,file"
hermes tools    # 대화형 도구 설정
```

### 도구 카테고리

| 카테고리 | 예시 도구 | 설명 |
|----------|-----------|------|
| Web | `web_search`, `web_extract` | 웹 검색·페이지 추출 |
| X Search | `x_search` | X(Twitter) 검색 (xAI 키 필요) |
| Terminal & Files | `terminal`, `read_file`, `patch` | 셸·파일 조작 |
| Browser | `browser_navigate`, `browser_snapshot` | 브라우저 자동화 |
| Media | `vision_analyze`, `image_generate`, `text_to_speech` | 비전·이미지·TTS |
| Agent | `todo`, `delegate_task`, `execute_code` | 계획·위임·코드 실행 |
| Memory | `memory`, `session_search` | 기억·과거 세션 검색 |
| Automation | `cronjob` | 예약 작업 |
| Integrations | `ha_*`, MCP 도구 | Home Assistant, MCP |

### 터미널 백엔드 (6종)

| Backend | 용도 |
|---------|------|
| `local` | 로컬 PC (기본) |
| `docker` | 격리 컨테이너 (persistent sandbox) |
| `ssh` | 원격 서버 (에이전트 코드와 분리) |
| `singularity` | HPC |
| `modal` | 서버리스 클라우드 |
| `daytona` | 클라우드 개발 샌드박스 |

## 2. 메모리 (Memory)

세션을 넘어 **선별된 기억**을 유지합니다.

| 파일 | 용도 | 한도 |
|------|------|------|
| `MEMORY.md` | 환경·프로젝트·학습 내용 | ~2,200자 |
| `USER.md` | 사용자 프로필·선호 | ~1,375자 |

위치: `~/.hermes/memories/`

### memory 도구 액션

- `add` — 항목 추가
- `replace` — 부분 문자열 매칭으로 수정
- `remove` — 삭제

### session_search

- 모든 CLI·메시징 세션이 `~/.hermes/state.db` (FTS5)에 저장
- "지난주에 X 논의했나?" 같은 질의에 사용

### 외부 Memory Provider (8종)

Honcho, OpenViking, Mem0, Hindsight, Holographic, RetainDB, ByteRover, Supermemory

```bash
hermes memory setup
hermes memory status
```

### write_approval

잘못된 기억 저장 방지:

```yaml
memory:
  write_approval: true   # 저장 전 승인
```

CLI: `/memory pending`, `/memory approve`, `/memory reject`

## 3. 스킬 (Skills)

**필요할 때만 로드**하는 절차적 지식 문서 (agentskills.io 표준).

위치: `~/.hermes/skills/` (~90 bundled)

### 사용법

```bash
/github-pr-workflow fix issue #123 and open a PR
/plan design auth migration
/learn the REST client in ~/projects/acme-sdk
```

스킬 체이닝 (최대 5개):

```bash
/github-pr-workflow /test-driven-development fix issue #123
```

### Progressive Disclosure (토큰 절약)

```
Level 0: skills_list()     → 이름·설명만
Level 1: skill_view(name)  → 전체 SKILL.md
Level 2: skill_view(name, path) → 참조 파일
```

### 에이전트가 스스로 만드는 스킬

- `/learn` — 문서·URL·대화에서 스킬 생성
- Curator — 사용량·노후 스킬 백그라운드 정리
- Skills Hub — 커뮤니티 스킬 공유

카탈로그: [[07 - Skills 카탈로그 요약]]
