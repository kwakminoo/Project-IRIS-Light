# Hermes — 설치와 설정

> Source: https://hermes-agent.nousresearch.com/docs/getting-started/installation  
> 정리일: 2026-07-20

## 설치 방법

| 플랫폼 | 명령 |
|--------|------|
| Windows (PowerShell) | `iex (irm https://hermes-agent.nousresearch.com/install.ps1)` |
| Linux / macOS / WSL2 | `curl -fsSL https://hermes-agent.nousresearch.com/install.sh \| bash` |
| Android (Termux) | 동일 install.sh |
| Hermes Desktop | https://hermes-agent.nousresearch.com 에서 GUI 설치 |

## 빠른 온보딩

```bash
hermes setup --portal    # Nous Portal OAuth — 모델 + Tool Gateway 한 번에
hermes setup             # 전체 설정 마법사
hermes gateway           # 메시징 + API Server 시작
```

### Ollama + Hermes (Iris Light 권장)

1. Ollama 실행 (`http://127.0.0.1:11434/v1`)
2. `ollama launch hermes` 또는 `hermes setup`
3. Provider: Custom endpoint → `http://127.0.0.1:11434/v1`, API key 비움
4. `hermes gateway` 실행

## 설정 파일 위치

| 경로 | 용도 |
|------|------|
| `~/.hermes/config.yaml` | 메인 설정 (provider, MCP, terminal, memory) |
| `~/.hermes/.env` | API 키, 이메일 비밀번호 등 시크릿 |
| `~/.hermes/skills/` | 스킬 (bundled + 사용자 생성) |
| `~/.hermes/memories/` | MEMORY.md, USER.md |
| `~/.hermes/state.db` | 세션 SQLite (FTS5 검색) |

## Provider 설정 (Ollama)

```yaml
# ~/.hermes/config.yaml 예시
providers:
  ollama:
    base_url: http://127.0.0.1:11434/v1
    api_key: ""
```

환경 변수로 Iris Light와 공유할 항목:

```bash
# Iris Light .env
IRIS_HERMES_ENABLED=1
IRIS_HERMES_BASE_URL=http://127.0.0.1:8642/v1
IRIS_HERMES_COMMAND=hermes
IRIS_HERMES_API_KEY=change-me-local-dev   # API_SERVER_KEY와 동일
```

## API Server 활성화

`~/.hermes/.env`:

```bash
API_SERVER_ENABLED=true
API_SERVER_KEY=change-me-local-dev
```

```bash
hermes gateway
# → [API Server] listening on http://127.0.0.1:8642
```

## Nous Portal (선택)

단일 OAuth로 **300+ 모델** + Tool Gateway(웹검색, 이미지, TTS, 브라우저) 사용.

```bash
hermes setup --portal
```

## 업데이트·제거

```bash
hermes update      # 최신 버전
# 제거: 설치 가이드의 uninstall 절차 참고
```

## Iris Light 연동 체크리스트

- [ ] `hermes --version` 동작
- [ ] Ollama 실행 중
- [ ] `hermes gateway` → `:8642` 리스닝
- [ ] Iris `.env` → `IRIS_HERMES_ENABLED=1`
- [ ] Iris 설정에서 Hermes API URL 확인
- [ ] 상태 헤더 HERMES 칩 → Connected
