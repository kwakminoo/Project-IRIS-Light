## 1) Email Gateway (Messaging)

Hermes **전용 메일함**에 보내면 에이전트가 스레드로 답장.

문서: https://hermes-agent.nousresearch.com/docs/user-guide/messaging/email

```bash
hermes gateway setup   # Email 선택
```

### Gmail 설정

```bash
EMAIL_ADDRESS=hermes@gmail.com
EMAIL_PASSWORD=xxxx xxxx xxxx xxxx   # Google App Password
EMAIL_IMAP_HOST=imap.gmail.com
EMAIL_SMTP_HOST=smtp.gmail.com
EMAIL_ALLOWED_USERS=your@gmail.com   # 보안 권장
EMAIL_POLL_INTERVAL=15
EMAIL_HOME_ADDRESS=your@gmail.com    # cron 결과 수신
```

- 2FA + [App Passwords](https://myaccount.google.com/apppasswords) 필수

### Naver 설정

```bash
EMAIL_ADDRESS=your@naver.com
EMAIL_PASSWORD=<애플리케이션 비밀번호>
EMAIL_IMAP_HOST=imap.naver.com
EMAIL_IMAP_PORT=993
EMAIL_SMTP_HOST=smtp.naver.com
EMAIL_SMTP_PORT=465
```

- 네이버 메일 → 환경설정 → **IMAP/SMTP 사용함**
- **2단계 인증** + **애플리케이션 비밀번호** (2025-06~ 필수)

### Gmail + Naver 동시 사용

Gateway는 **1계정** 중심 → **Himalaya 다계정** 또는 계정별 forward 권장.

## 2) Himalaya 스킬 (`email/himalaya`)

터미널 IMAP/SMTP 클라이언트 — **다중 계정** TOML 설정.

```bash
/himalaya list inbox
```

`~/.config/himalaya/config.toml` 예:

```toml
[accounts.gmail]
email = "you@gmail.com"
default = true
backend.type = "imap"
backend.host = "imap.gmail.com"
backend.port = 993
# … SMTP, folder aliases (Gmail Sent 등)

[accounts.naver]
email = "you@naver.com"
backend.host = "imap.naver.com"
# …
```

Hermes 채팅 예:

- "네이버 받은편함 최근 10통 요약"
- "Gmail에서 ○○님 메일 찾아 답장 초안"

## Iris Light 이메일 UI (로드맵)

현재 Iris **이메일 아이콘 = 준비 중**.

목표 아키텍처:

```
[Email 아이콘] → EmailWorkspacePage
    ├─ 받은편함 (Hermes/Himalaya 결과)
    ├─ 본문 미리보기
    └─ 작성 → HermesChatWorker
```

Iris는 **프로토콜 구현 없이** Hermes AgentPort만 사용 (`docs/domain.md`).
