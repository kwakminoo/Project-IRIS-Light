# Iris Light 프로젝트 개요

> Generated-at: 2026-07-20  
> Source: Project-IRIS-Light-main

## 한 줄 정의

**Iris Light**는 PyQt6 기반 데스크톱 HUD로, **Ollama** 모델과 (선택) **Hermes Agent**를 UI에서 연결해 채팅·모니터링·워크스페이스 전환을 제공합니다.

## 기술 스택

| 영역 | 구성 |
|------|------|
| UI | PyQt6, 커스텀 HUD 테마 |
| AI | Ollama OpenAI 호환 API (`/v1`) |
| 에이전트 | Hermes (선택, `IRIS_HERMES_ENABLED`) |
| 저장소 | `~/.iris-light/iris_light.db` (SQLite) |
| Android | 프로젝트 `android-emulator/` (AVD·userdata) |

## 폴더 구조

```
Project-IRIS-Light-main/
├── iris/                 # 앱 소스
│   ├── ui/               # HUD·채팅·워크스페이스
│   ├── infrastructure/   # Ollama·Hermes 클라이언트
│   ├── system/           # 메트릭·Android 에뮬레이터
│   └── knowledge/        # Obsidian vault 로더
├── android-emulator/
│   ├── avd/              # IrisLight_Pixel AVD (32GB 내부 저장)
│   └── data/             # 에뮬레이터 userdata
├── obsidian-vault/       # 이 Wiki
├── requirements.txt
├── run.bat
└── .env                  # 로컬 설정 (git 제외)
```

## 실행

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
run.bat
```

## 환경 변수 (`.env`)

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `IRIS_OLLAMA_BASE_URL` | `http://127.0.0.1:11434/v1` | Ollama API |
| `IRIS_OLLAMA_MODEL` | (비움) | 기본 모델 |
| `IRIS_HERMES_ENABLED` | `1` | Hermes 사용 여부 |

## HUD 아이콘

- **모바일**: `android-emulator/` AVD 실행
- **Obsidian**: 이 vault를 앱 내 Wiki로 표시
- **기타 아이콘**: IDE·메신저·**이메일** 등 (준비 중)
