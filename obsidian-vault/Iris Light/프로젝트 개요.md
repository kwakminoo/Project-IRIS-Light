# Iris Light 프로젝트 개요

> Generated-at: 2026-08-25  
> Source: Project-IRIS-Light · 버전 `0.1.0-light` · 표시 이름 **IRIS**

## 한 줄 정의

**IRIS(Iris Light)** 는 PyQt6 기반 데스크톱 HUD로, **Ollama**(모델)와 **Hermes Agent**(도구·스킬·MCP)를 UI에서 연결해 채팅·워크스페이스·모니터링을 제공합니다.

## 기술 스택

| 영역 | 구성 |
|------|------|
| UI | PyQt6, PyQt6-WebEngine, 커스텀 HUD |
| AI | Ollama (`:11434`, OpenAI 호환 `/v1`) |
| 에이전트 | Hermes Gateway (`:8642`) |
| 역제어 | Control Surface (`:8765`) + iris-control MCP/스킬 |
| 저장소 | `~/.iris-light/iris_light.db` (SQLite) |
| 음성(선택) | FastAPI Voice Runtime (`:18765`, `.venv-voice`) |
| Android(선택) | `android-emulator/avd/` (IrisLight_Pixel) |

## 실행

```bat

run.bat
```

또는:

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
python -m iris
```

## 환경 변수 (`.env`)

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `IRIS_OLLAMA_BASE_URL` | `http://127.0.0.1:11434` | Ollama (클라이언트는 `/v1` 정규화) |
| `IRIS_OLLAMA_MODEL` | (비움) | 기본 모델 — 앱에서 선택 |
| `IRIS_HERMES_ENABLED` | `1` | Hermes 사용 |
| `IRIS_HERMES_BASE_URL` | `http://127.0.0.1:8642` | Hermes Gateway |
| `IRIS_HERMES_API_KEY` | (위저드) | Gateway API 키 |
| `IRIS_CONTROL_*` | host/port `8765` | Control Surface (선택) |
| `IRIS_DATA_GO_KR_SERVICE_KEY` | — | 공휴일 API (캘린더) |

웹검색 키(SerpApi/Exa/Firecrawl/Naver)는 **Hermes** `%LOCALAPPDATA%\hermes\.env`에 둡니다.
