# Iris Light 프로젝트 개요

> Generated-at: 2026-10-28  
> Source: Project-IRIS-Light · 버전 `0.1.0-light` · 표시 이름 **IRIS**

## 한 줄 정의

**IRIS(Iris Light)** 는 PyQt6 기반 데스크톱 HUD로, **Ollama**(모델)와 **Iris Agent**(도구·스킬·MCP)를 한 제품으로 묶어 채팅·워크스페이스·모니터링을 제공한다.

## 기술 스택

| 영역 | 구성 |
|------|------|
| UI | PyQt6, PyQt6-WebEngine, 커스텀 HUD |
| AI | Ollama (`:11434`, OpenAI 호환 `/v1`) |
| 에이전트 | Iris Agent (기본 InternalSidecar, 홈 `~/.iris-light/agent`) |
| 역제어 | Control Surface (`:8765`) + iris-control MCP/스킬 (compat) |
| 저장소 | `~/.iris-light/iris_light.db` (SQLite) |
| 음성(선택) | FastAPI Voice Runtime (`:18765`, `.venv-voice`) |
| Android(선택) | `android-emulator/avd/` (IrisLight_Pixel) |

## 실행

```bat

run.bat
```

또는:

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
python -m iris
```

## 환경 변수 (`.env`)

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `IRIS_OLLAMA_BASE_URL` | `http://127.0.0.1:11434` | Ollama (클라이언트는 `/v1` 정규화) |
| `IRIS_OLLAMA_MODEL` | (비움) | 기본 모델 — 앱에서 선택 |
| `IRIS_HERMES_ENABLED` | `1` | Iris Agent 필수 게이트(레거시 키명) |
| `IRIS_AGENT_HOME` | (비움) | 비우면 `~/.iris-light/agent` |
| `IRIS_HERMES_BASE_URL` | `http://127.0.0.1:8642` | ExternalGateway 옵션 |
| `IRIS_CONTROL_*` | host/port `8765` | Control Surface (compat) |
| `IRIS_DATA_GO_KR_SERVICE_KEY` | — | 공휴일 API (캘린더) |

웹검색 키(SerpApi/Exa/Firecrawl/Naver)는 **Iris Agent** `~/.iris-light/agent/.env`에 둔다.
