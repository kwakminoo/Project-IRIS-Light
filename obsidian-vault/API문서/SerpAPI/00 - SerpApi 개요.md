# SerpApi 개요

> Source: https://serpapi.com  
> 정리일: 2026-07-21

SerpApi는 검색 엔진의 결과(SERP)를 스크래핑해 구조화된 JSON으로 반환하는 API 서비스다.

- 공통 엔드포인트: `https://serpapi.com/search`
- 엔진 선택은 `engine` 파라미터로 지정 (예: `yahoo_images`).
- 인증은 `api_key` 파라미터 사용.
