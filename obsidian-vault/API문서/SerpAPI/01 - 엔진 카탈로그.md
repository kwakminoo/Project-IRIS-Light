# SerpApi — 엔진(engine) 카탈로그

> Source: https://serpapi.com/search-api (API Documentation 사이드바)  
> 정리일: 2026-07-22  
> 공통 엔드포인트: `https://serpapi.com/search.json?engine=<ENGINE>&api_key=...`

Iris Light / Hermes 연동:

- Hermes 빌트인: `web.search_backend: serpapi` → `web_search` 도구
- Hermes 스킬: `serpapi` (`%LOCALAPPDATA%\hermes\skills\iris-apis\serpapi\`)
- 플러그인: `plugins/web/serpapi` (소스: `integrations/hermes-plugins/web/serpapi/`)
- Env: `SERPAPI_API_KEY`, optional `SERPAPI_DEFAULT_ENGINE`

## 핵심

| 항목 | 값 |
|------|-----|
| Base | `https://serpapi.com/search.json` |
| 엔진 전환 | 쿼리 파라미터 `engine` (엔드포인트 추가 연결 불필요) |
| 인증 | `api_key` |

| engine | 용도 | 질의 파라미터 |
|--------|------|----------------|
| `google` | Google 웹검색 (기본) | `q` |
| `google_light` | Google Light | `q` |
| `google_images` | 이미지 | `q` |
| `google_news` | 뉴스 | `q` |
| `google_videos` | 동영상 | `q` |
| `google_maps` | 지도 | `q` |
| `google_local` | 로컬 | `q` |
| `google_shopping` | 쇼핑 | `q` |
| `google_scholar` | 학술 | `q` |
| `google_jobs` | 채용 | `q` |
| `google_flights` | 항공 | `q` |
| `google_hotels` | 호텔 | `q` |
| `google_finance` | 금융 | `q` |
| `google_autocomplete` | 자동완성 | `q` |
| `google_patents` | 특허 | `q` |
| `google_trends` | 트렌드 | `q` |
| `google_play` | Play 스토어 | `q` |
| `google_lens` | Lens | `url` |
| `bing` / `bing_images` / `bing_news` / `bing_videos` | Bing | `q` |
| `yahoo` / `yahoo_images` / `yahoo_videos` | Yahoo | `p` |
| `duckduckgo` / `duckduckgo_news` | DuckDuckGo | `q` |
| `baidu` / `baidu_news` | Baidu | `q` |
| `yandex` / `yandex_images` | Yandex | `text` |
| `youtube` | YouTube | `search_query` |
| `amazon` | Amazon | `k` |
| `ebay` | eBay | `_nkw` |
| `walmart` | Walmart | `query` |
| `home_depot` | Home Depot | `q` |
| `yelp` | Yelp | `find_desc` |
| `tripadvisor` | Tripadvisor | `q` |
| `naver` | Naver (SerpApi) | `query` |
| `apple_app_store` | App Store | `term` |

문서에 더 많은 API(Ads, Reviews, Product details 등)가 있으며, 동일하게 `engine=<이름>` 패턴이다. 전체는 SerpApi 대시보드 → API Documentation.

## 호출 예

```bash
curl "https://serpapi.com/search.json?engine=google&q=Coffee&api_key=YOUR_KEY"
curl "https://serpapi.com/search.json?engine=yahoo_images&p=Coffee&api_key=YOUR_KEY"
```

Hermes 스킬:

```bash
python %LOCALAPPDATA%\hermes\skills\iris-apis\serpapi\scripts\serpapi_search.py google "Coffee" 5
```
