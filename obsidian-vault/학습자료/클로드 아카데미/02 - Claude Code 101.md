# Claude Code 101

> Source: https://anthropic.skilljar.com/claude-code-101  
> 정리일: 2026-07-21  
> 출처: Anthropic Academy (Claude Academy)

일상 개발 워크플로에서 Claude Code를 효과적으로 사용하는 방법을 배우는 강좌. **동영상 강의(YouTube) 13개**로 구성되며, 각 레슨은 아래 영상으로 학습한다.

## 학습 목표

- AI 코딩 에이전트가 무엇인지, Claude Code가 채팅형 AI 도구와 어떻게 다른지 설명한다.
- 에이전트 루프, 컨텍스트 윈도우, 도구, 권한이 어떻게 함께 작동하는지 이해한다.
- 터미널, VS Code, JetBrains, Claude Desktop, 웹에서 Claude Code를 설치·설정한다.
- 승인 모드(approval), 자동 수락(auto-accept), Plan Mode로 효과적인 프롬프트를 작성한다.
- Explore → Plan → Code → Commit 워크플로를 따른다.
- `/compact`, `/clear`, `/context`로 컨텍스트 윈도우를 관리한다.
- `CLAUDE.md` 파일로 프로젝트 영구 메모리를 부여한다.
- 커스텀 subagent를 만들어 작업을 위임하고 메인 컨텍스트를 깔끔하게 유지한다.
- MCP 서버로 외부 도구·데이터 소스를 연결한다.
- hooks로 포매팅·명령 차단·알림을 결정론적으로 제어한다.

**전제 조건:** 코드 에디터와 커맨드라인 기본 사용 경험, Claude 계정(Pro/Max/Enterprise) 또는 API 키.
