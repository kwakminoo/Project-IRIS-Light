# Introduction to Model Context Protocol

> Source: https://anthropic.skilljar.com/introduction-to-model-context-protocol  
> 정리일: 2026-07-21  
> 출처: Anthropic Academy (Claude Academy)

Python으로 MCP 서버와 클라이언트를 처음부터 만드는 법을 배우는 강좌. MCP의 3가지 핵심 프리미티브 — **도구(tools), 리소스(resources), 프롬프트(prompts)** — 를 익힌다. **동영상 강의 14개**(플랫폼 내장 동영상, 외부 링크/자막 없음 → 사이트에서 시청).

---

## 커리큘럼 (학습 순서)

1. Welcome to the course (동영상)
2. Introducing MCP (동영상) — MCP 소개
3. MCP clients (동영상) — MCP 클라이언트
4. Project setup (동영상) — 프로젝트 설정
5. Defining tools with MCP (동영상) — MCP로 도구 정의
6. The server inspector (동영상) — 서버 인스펙터
7. Course satisfaction survey (설문)
8. Implementing a client (동영상) — 클라이언트 구현
9. Defining resources (동영상) — 리소스 정의
10. Accessing resources (동영상) — 리소스 접근
11. Defining prompts (동영상) — 프롬프트 정의
12. Prompts in the client (동영상) — 클라이언트에서 프롬프트 사용
13. Final assessment on MCP (최종 평가)
14. MCP review (동영상) — 복습

> 핵심 개념: MCP는 LLM 애플리케이션에 **도구·리소스·프롬프트**를 표준화된 방식으로 연결하는 프로토콜이다. 심화 내용은 [[11 - Model Context Protocol - Advanced Topics]] 참고.
