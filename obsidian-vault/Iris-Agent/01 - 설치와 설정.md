# Iris Agent — 설치와 설정

> 정리일: 2026-10-28  
> 제품 정본: `docs/domain.md` · `docs/ia/IA.md`

## 설치 방법 (Iris Light)

| 경로 | 설명 |
|------|------|
| Setup Protocol | 첫 실행 시 Ollama + Iris Agent 런타임(pin) |
| supervisor | `ensure_iris_agent_runtime` — 수명·헬스 |
| pin | `vendor/iris-agent-runtime/PIN` |

별도 업스트림 설치 스크립트로 `%LOCALAPPDATA%\hermes`만 쓰는 방식은 **활성 제품 홈이 아니다** (마이그레이션 잔여 가능).

## 빠른 온보딩

1. Ollama 실행 (`http://127.0.0.1:11434`)
2. Iris 실행 (`dist\IRIS.exe` 또는 `pythonw -m iris`)
3. Setup이 Iris Agent 홈을 준비
4. 채팅은 기본 InternalSidecar

## 설정 파일 위치

| 경로 | 용도 |
|------|------|
| `~/.iris-light/agent/config.yaml` | provider, MCP, terminal, memory |
| `~/.iris-light/agent/.env` | API 키 등 시크릿 |
| `~/.iris-light/agent/skills/` | 스킬 (동봉 + sync) |
| `~/.iris-light/iris_light.db` | Iris 채팅 정본 |
| `vendor/iris-agent-runtime/PIN` | 런타임 SHA |

## Provider 설정 (Ollama)

```yaml
# ~/.iris-light/agent/config.yaml 예시
providers:
  ollama:
    base_url: http://127.0.0.1:11434/v1
    api_key: ""
```

환경 변수:

| 변수 | 설명 |
|------|------|
| `IRIS_AGENT_HOME` | 비우면 `~/.iris-light/agent` |
| `IRIS_OLLAMA_BASE_URL` | Ollama base |
| `IRIS_HERMES_ENABLED` | Iris Agent 필수 게이트(레거시 키명) |
